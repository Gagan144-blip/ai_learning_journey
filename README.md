# AI Learning Journey

This workspace is ready for Python practice with NumPy, pandas, Matplotlib, and Jupyter.

## Start in VS Code

1. Open this folder in VS Code.
2. Select the interpreter ending in `.venv\\Scripts\\python.exe` if VS Code asks.
3. Open `hello_python.py` and choose **Run Python File**.

## Terminal commands

```powershell
.\.venv\Scripts\Activate.ps1
python hello_python.py
jupyter lab
```

To install the same packages again:

```powershell
python -m pip install -r requirements.txt
```
